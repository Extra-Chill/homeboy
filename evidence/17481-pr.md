# Resolve component checkouts before Lab gate preflight

Fixes #17481
Refs #17455

## Root cause
Configured component identities omit repository_path. Cook gate preflight fell back to the controller invocation cwd, so invocations from /tmp snapshotted unrelated, changing files (including dangling entries) before candidate creation. This explains the identical request digest across repositories and the absence of task worktree records; it was not evidence of candidate cleanup racing the handoff.

## Change
Resolve the configured component checkout before preflight, preserving explicit cwd/repository-path precedence. Materialization filesystem boundaries use a shared helper to record operation, path and controller/runner side in messages and details, with retryable unavailable disposition. Keep strict worktree identity validation: update stale runner fixtures and the core inventory fixture to carry identities consistent with their handles.
